# Política de Privacidade e Proteção de Dados (LGPD)
**Status:** [Minuta institucional — pendente de validação profissional]

---

## 1. Objetivo
Garantir a conformidade integral com a Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018).

## 2. Tratamento de Dados de Saúde
Prontuários médicos, fichas de avaliação multidimensional e históricos de saúde dos moradores são classificados como dados sensíveis e mantidos sob guarda digital criptografada com acesso restrito à equipe técnica autorizada.

## 3. Direitos dos Cadastrados
Qualquer usuário cadastrado nos formulários web poderá solicitar alteração, anonimização ou exclusão dos seus dados mediante simples comunicação.
