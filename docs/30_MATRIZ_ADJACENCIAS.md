## 2. Diagramas Textuais dos Fluxos de Circulação

### A. Fluxo de Moradores
`Suíte Privativa ➔ Corredor Acessível ➔ Jardim Central ➔ Refeitório / Capela / Fisioterapia`

### B. Fluxo de Visitantes
`Estacionamento ➔ Recepção / Espera ➔ Sala de Atendimento / Praça da Família ➔ (Acesso a Suítes apenas com autorização)`

### C. Fluxo de Alimentação
`Recepção de Insumos ➔ Despensa / Câmaras ➔ Cozinha / Preparo ➔ Copa de Apoio ➔ Refeitório ➔ Higienização de Utensílios`

### D. Fluxo de Rouparia (Segregação Limpo x Sujo)
- **Roupa Suja:** `Suítes ➔ Carrinho fechado expurgo ➔ Lavanderia (Área Suja) ➔ Lavagem/Termodesinfecção`
- **Roupa Limpa:** `Lavanderia (Área Limpa) ➔ Passadoria ➔ Rouparia Central ➔ Distribuição nas Suítes`

### E. Fluxo de Emergência Médica
`Suíte / Banheiro (Acionamento de Alarme) ➔ Posto de Enfermagem ➔ Atendimento Inicial ➔ Rota Coberta sem barreiras ➔ Ambulância (Doca de Emergência)`
